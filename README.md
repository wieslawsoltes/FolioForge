# FolioForge — Editorial Studio

A local-first desktop-publishing editor built with plain HTML, CSS, JavaScript, and a WebGPU compositor with Canvas 2D fallback.

The complete v0.1 source, original artwork, editable six-page sample, standalone edition, documentation, and tests are being imported into this repository.

Live application: https://wieslawsoltes.github.io/FolioForge/

The Pages workflow validates the source and deploys the application on pushes to `main`.
